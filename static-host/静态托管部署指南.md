# 让工作台"独立常开"——静态托管迁移指南

Cloud Studio 的预览链接依赖工作空间进程（终端一关就失效）。
迁移到**静态托管**后：文件放云端，永久在线，与终端/工作空间无关。

你的站点是**单个 index.html、零依赖、零构建**，所以迁移 = 把 index.html 上传一次。

---

## 方案 A：腾讯云「静态网站托管」（推荐 · 与 Cloud Studio 同账号）

1. 打开 https://console.cloud.tencent.com/tcb （腾讯云·云开发控制台，用你登录 Cloud Studio 的同一个腾讯账号）
2. 首次使用按引导开通「云开发」环境（选**按量计费/免费体验套餐**即可）
3. 左侧菜单进入「**静态网站托管**」→ 进入默认环境
4. 点「**上传文件**」→ 把本目录的 `index.html` 拖进去
5. 页面会给出一个**永久链接**（形如 `https://<env>-xxxxxxxx.tcloudbaseapp.com`）
6. 打开即用，随时可访问，**无需终端、无需保持任何进程**

## 方案 B：腾讯云 COS 对象存储（备选）

1. 打开 https://console.cloud.tencent.com/cos
2. 「创建存储桶」→ 名称随意、地域选「上海/北京」、**访问权限选「公有读私有写」**
3. 上传 `index.html`
4. 「存储桶配置」→「基础配置」→「静态网站」→ 开启，索引文档填 `index.html`
5. 得到链接：`https://<bucket>.cos.<region>.myqcloud.com`（也可绑定自定义域名）

## 方案 C：Gitee Pages（免费，国内访问快）

1. 在 gitee.com 新建仓库 → 上传 `index.html`
2. 仓库「服务」→「Gitee Pages」→ 启动（首次需实名认证）
3. 得到 `https://<用户名>.gitee.io/<仓库名>/` 永久链接

---

## 提醒

- 三个方案都只上传 **index.html 一个文件**，其它文件（README/脚本）不需要。
- 换域名/换浏览器后，网页数据（localStorage）不跟随；用页面里的
  「进度管理 → 导出 JSON」保存，在新地址「导入 JSON」即可恢复。
- 静态托管免费额度对个人学习站完全够用；后续若流量大再考虑绑域名或升级。
