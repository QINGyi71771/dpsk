## 四、快速开始

```powershell
cd D:\dpsk\考研备考

# 1. 今天该干什么（按你选定的方案自动切版本）
#    周一~周五 → 版本 B（有课型，约 6h）
#    周六      → 版本 A（全天型，约 10.5h）
#    周日      → 版本 C（复盘 + 六级听力专项）
python tools\tracker.py today

# 2. 每天必做：录入（交互式，直接回车用默认值）

python tools\tracker.py add-session     # 录学习时长
python tools\tracker.py add-paper       # 录模考成绩

# 3. 每天先看这个：艾宾浩斯到期复习提醒
python tools\tracker.py review
python tools\tracker.py review --done 3 # 复习完 3 条后标记

# 4. 每周日：看报表 + 刷新 Excel 仪表盘
python tools\tracker.py report
python tools\tracker.py excel
```

> 脚本只依赖 Python 3 标准库 + `openpyxl`（已安装）。中文输出已强制 UTF-8。

## 五、数据录入规范（决定数据有没有用）

**错题必填 3 项，缺一项这条错题就白记了：**

| 字段 | 要求 | 反例（无效） |
|---|---|---|
| 考点 | 精确到可检索 | ❌「几何」 ✅「球内接正方体大圆截面」 |
| 根本原因 | 写「我为什么会那样想」 | ❌「粗心」 ✅「在立体图里硬想，没有画二维截面降维」 |
| 避坑口诀 | 一句可复用的动作指令 | ❌「下次注意」 ✅「球的问题先画大圆截面，把三维压成三角形」 |

**时长录入每天做，不要攒到周末。** 攒着补录的信息失真率极高，看不出节奏问题。

## 六、与我（AI 助手）的交互协议

直接把下面模板贴给我即可，我会按固定结构回你诊断，不需要客套开场。

### 1️⃣ 数学 / 逻辑错题

```
【科目】数学
【来源】2021 管综第 15 题
【题目】（文字或图片）
【我的答案】B  【正确答案】D
【我的思路】我当时想……
```

**我会返回：** 考点本质还原 → 你的错因定位（是概念 / 方法 / 陷阱 / 时间）→ 正确入口与最短路径 → 一条可复用的避坑口诀 → 同类题的识别特征。

### 2️⃣ 英语长难句 / 阅读错题

```
【句子或题目】……
【我不确定的】主干划分 / 指代对象 / 转折逻辑 / 干扰项为什么错
【我的选择】B  【答案】D
```

**我会返回：** 句子主干骨架 → 修饰成分归属 → 该题在原文的定位句 → **干扰项属于哪一类陷阱**（偷换概念 / 范围扩大 / 无中生有 / 因果倒置 / 张冠李戴）。

### 3️⃣ 管综作文

```
【类型】论证有效性分析（或论说文）
【题目材料】……
【我的成文】……
【用时】xx 分钟
```

**我会返回：** 按评分点逐项打分 → 指出你**漏掉的漏洞**（论证有效性分析）或**立意偏差 / 结构塌陷**（论说文）→ 给出改写后的段落示范，而不是泛泛评价。

### 4️⃣ 需要计划调整时

告诉我三件事：**本周实际完成量 / 卡住的地方 / 剩余可用时间**，我改计划而不是劝你努力。

## 七、执行铁律

1. **核心块 ≥ 3 个才算达标日**：数学专项、逻辑专项、英语精读、写作输出——一天至少完成 3 个。
2. **连续 2 天未达标 → 立刻下调任务量**，不要硬撑到崩盘。可持续 > 强度。
3. **每晚 21:10 固定录入数据**。不录入 = 没发生。
4. **周日不排新内容**：只做错题清零 + 六级听力精听 + 全科小模考 + 周复盘。
5. **50 秒舍弃原则**：考场上一题思考 50 秒无思路立即标记跳过，基础分优先。
6. **写作是最容易被放弃的提分模块**——它不依赖天赋，只依赖输出次数。每周固定 2 篇成文，不许延期。
